怎么导出账单？
🅰️ 支付宝
App → 我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 选择「用于个人对账」 → 选好时间范围 → 填邮箱 → 收到带解压码的 zip，解压出 CSV 后上传。
💚 微信
微信 → 我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单下载 → 选择「用于个人对账」→ 选时间范围 → 邮件收到带密码的压缩包，解压出 CSV 后上传。
🏦 银行卡
各银行 App 一般都有「交易明细导出」，导出 CSV 后选「其他通用 CSV」上传即可。
隐私说明
文件只在你的浏览器本地解析，不会上传到任何服务器。 支付宝/微信没有开放个人账单 API，官方 CSV 导入是最稳定合规的方式。
