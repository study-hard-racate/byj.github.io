# 个人财务看板 + 习惯健康追踪

一个跑在你自己电脑上的 Flask 小网页，用来回答两个问题：**钱花在哪了**、**最近状态怎么样**。

数据全部存在本地 SQLite 文件里，不联网、不上传、没有广告。

---

## 一、跑起来

```bash
# 1. 装依赖（建议先建虚拟环境）
pip install -r requirements.txt

# 2.（可选）先塞一批演示数据，打开就有图可看
python seed_demo.py

# 3. 启动
python app.py
```

浏览器打开 **http://127.0.0.1:5000**

> 第一次启动会自动创建 `data/app.db`，不用手动建库。

## 二、怎么导出账单

### 支付宝

```
App → 我的 → 账单 → 右上角「…」→ 开具交易流水证明
    → 用于个人对账 → 选时间范围 → 填邮箱
```
会收到一封邮件，附件是**带解压码的 zip**，解压后得到 CSV —— 这个 zip 或解压后的 CSV 都能直接上传。

### 微信

```
微信 → 我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单下载
    → 用于个人对账 → 选时间范围 → 填邮箱
```
同样是邮件收到带密码的压缩包。

### 银行卡

各银行 App 找「交易明细导出」，导出 CSV 后在导入页选「其他通用 CSV」。格式差异大时，直接用**手动记一笔**补上也很快。

### 关于「自动同步」

支付宝和微信都没有开放个人账单 API。所谓自动同步基本靠逆向 App 私有协议，**随时会失效，且有封号风险**。所以这里走官方 CSV 导入：稳定、合规，导一个月大概 30 秒。

> 小技巧：设个每月一次的日历提醒，花 1 分钟导一次，比任何自动化都靠谱。

## 三、功能

### 💰 财务

| 功能 | 说明 |
|---|---|
| 导入账单 | 支持支付宝 / 微信 / 通用 CSV，也支持 zip 直接传；**按内容指纹自动去重**，同一份文件导两次不会重复 |
| 自动分类 | 内置 100+ 条规则（瑞幸→餐饮·咖啡、滴滴→交通·打车、嘉立创→购物·元器件…）。支付宝自带的分类质量不错，会被优先采用 |
| 手动改分类 | 在明细里点分类标签就能改，**顺手记住这个商户**，下次自动归对 |
| 可视化 | 分类环形图、月度收支趋势（柱=支出 / 线=结余）、每日支出走势、Top 商户排行 |
| 筛选 | 按月份 / 分类 / 来源 / 收支方向 / 关键词组合筛选 |
| 手动记账 | 现金消费、银行卡补记都能加 |
| 导出 | 一键导出全量账单 CSV（带 BOM，Excel 打开中文不乱码） |

### ❤️ 健康

每天 20 秒打卡：**睡眠时长 / 睡眠质量 / 心情 / 体重 / 运动分钟 / 步数 / 专注时长 / 备注**

- 同一天重复提交会覆盖，不用担心记重
- 图表会**自动跳过没有记录的天**（断线，而不是画成 0 误导你）
- 连续打卡天数、达标天数、体重变化全都算好
- 打卡日历热力图，一眼看出哪几天偷懒了

## 五、常见问题

**Q：数据存在哪？怎么备份？**
在 `data/app.db`。直接复制这个文件就是完整备份。想换位置：

```bash
# Linux / macOS
PD_DB_PATH=/你的网盘目录/app.db python app.py

# Windows PowerShell
$env:PD_DB_PATH="D:\syncthing\app.db"; python app.py
```

放到网盘目录还能多设备同步（注意别两台电脑同时开）。

**Q：想用手机访问？**

```bash
HOST=0.0.0.0 python app.py
```
然后手机连同一个 WiFi，访问电脑的局域网 IP（如 `http://192.168.1.23:5000`）。

**Q：分类分错了？**
在「财务账单」页点那条记录的分类标签，改成正确的，勾上「记住这个商户」即可。改完点「🔄 重跑分类」能批量修正历史记录（不会覆盖你手动改过的）。

也可以在「导入与规则」页直接管理规则表，优先级数字越大越先生效。

**Q：导入没反应 / 提示找不到表头？**
确认上传的是**官方导出的原始 CSV**，别用 Excel 另存过（会改编码丢格式）。支付宝的 GBK、微信的 UTF-8-BOM 都做了自动识别。

**Q：某些记录没被统计？**
交易状态是「已退款 / 交易关闭」的会被自动跳过；「零钱提现 / 信用卡还款」这类内部转账标记为「不计收支」，在筛选里单独可见，不参与收支计算。

**Q：健康数据只有折线，点和点之间断开了？**
故意的。断线代表那天没打卡，画成 0 会让你误以为「睡了 0 小时」。

## 六、想改着玩

几个好上手的扩展点：

- **预算功能**：在 `models.py` 加一张预算表，在 `api_summary` 里算「本月还剩多少」，页面加个进度条
- **记账提醒**：写个脚本每天定时检查今天有没有打卡，没打就发系统通知
- **年度复盘**：加个 `/year` 页面，按分类汇总全年，做个「年度最大一笔支出」的卡片
- **多币种 / 报销标记**：给 `Transaction` 加字段，筛选里加个开关
