怎么导出账单？
🅰️ 支付宝
App → 我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 选择「用于个人对账」 → 选好时间范围 → 填邮箱 → 会收到带解压码的 zip，解压后就是 CSV。
💚 微信
微信 → 我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单下载 → 选择「用于个人对账」→ 选时间范围 → 同样会邮件发你一个带密码的压缩包。
🏦 银行卡
各银行 App 一般都有「交易明细导出」，导出 CSV 后选「其他通用 CSV」上传即可。 格式不标准时可在下方反馈，或用「手动记一笔」补记。
关于「自动同步」
支付宝/微信没有开放个人账单 API，任何"自动同步"都要逆向私有协议， 随时会失效且有封号风险。所以这里用官方 CSV 导入 —— 稳定、合规，30 秒能导完一个月。
