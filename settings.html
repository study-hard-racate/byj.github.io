🎨 品牌显示在侧边栏和浏览器标题
主题色在 js/config.js 的 accent 里改
💰 本月预算总览页显示进度条，超支会提醒
⏰ 提醒只在打开网站时生效（纯前端无法后台定时）
📲 安装到桌面全屏 App 体验 · 离线可用
iPhone/iPad：用 Safari 打开本站 → 点底部「分享」按钮（⬆️方框箭头）→ 「添加到主屏幕」→ 确认。之后从桌面图标打开就是全屏 App。
• Android：Chrome 打开本站会弹出「安装应用」提示；没弹的话点右上角 ⋮ →「安装应用」， 或等本站出现「一键安装」按钮（首次访问后触发）。
• 装好后桌面会出现 B 字图标，点开即全屏运行，断网也能用。
• ⚠️ 每个设备的数据是独立的：换设备后请在「数据管理」里导出备份 → 新设备导入。
💾 数据管理所有数据都存在你的浏览器本地
• 换电脑 / 换浏览器：导出 JSON → 在新浏览器打开本站 → 导入备份，数据就过去了。
• 也可以随时把账单导出成 CSV（财务页 / 健康页顶部按钮），Excel 可直接打开。
• 建议每月导出一次备份，或把 JSON 存到网盘。
